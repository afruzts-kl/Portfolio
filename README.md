# Afruz T S — Portfolio

Personal portfolio for **Afruz T S**, First Year CSE student at **Ilahia College of Engineering**.

## Stack
- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
